## Como executar

1. Instale o **Python 3** e abra a pasta do projeto no **PyCharm** (ou use um terminal).
2. Escolha a atividade e abra o arquivo `.py` correspondente.
3. Execute o código e informe os valores solicitados.
4. Compare o resultado com as condições descritas no enunciado do PDF.

Exemplo pelo terminal, a partir da raiz do projeto:

```powershell
python .\atividades\atividade-01\atividade_01.py
```

> No Windows, se `python` não estiver disponível, experimente `py`.

## Versionamento no GitHub

Os arquivos `README.md` e `.gitignore` já estão incluídos no projeto. O `.gitignore` exclui ambientes virtuais, arquivos temporários e caches, mas **não exclui os códigos Python nem as imagens dos fluxogramas**.

Para um repositório Git que já foi publicado e está sincronizado:

```powershell
git status
git add .
git commit -m "docs: adiciona documentacao do projeto"
git push
```

Para criar um repositório novo, inicialize o Git na **pasta raiz desta versão** e conecte-o a um repositório remoto vazio. Evite inicializar repositórios separados dentro de cada exercício.
